# HR Compliance Tracker

## Project Overview
This project demonstrates how an HR professional can monitor employee compliance documents and identify documents that are expiring or have expired.

## Purpose
The tracker helps HR teams organise compliance information, follow up on outstanding documents, and maintain accurate records.

## Information Tracked
- Employee reference number
- Department or work site
- Document type
- Issue date
- Expiry date
- Compliance status
- Follow-up action required

## Compliance Status
- **Valid:** Document is still current.
- **Expiring Soon:** Document requires renewal follow-up.
- **Expired:** Immediate follow-up is required.

## HR Value
This project demonstrates skills in HR administration, compliance monitoring, record keeping, reporting, and risk prevention.

## Data Privacy
This is a demonstration project. All sample information should be fictional. No real employee personal information or confidential company records should be uploaded.

## Skills Demonstrated
- HR compliance administration
- Document tracking
- Data organisation
- Risk monitoring
- Reporting and follow-up
