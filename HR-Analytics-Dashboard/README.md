# HR Analytics Dashboard

## Project Overview
This project demonstrates how HR data can be organised and analysed to support workforce planning, recruitment decisions, employee retention, and management reporting.

## Project Objectives
- Monitor employee headcount.
- Track recruitment activity.
- Analyse employee turnover.
- Monitor absenteeism trends.
- Present HR information in a clear, structured format.

## Key HR Metrics

### 1. Employee Headcount
The total number of employees at a particular point in time.

### 2. Recruitment Activity
Tracks vacancies, applications, interviews, offers, and appointments.

### 3. Employee Turnover
Measures the rate at which employees leave an organisation during a defined period.

### 4. Absenteeism
Tracks absence patterns to help HR identify trends and improve workforce planning.

### 5. Compliance Status
Monitors the status of required employee documents and outstanding follow-ups.

## Example Dashboard Layout
A dashboard could include:
- Total active employees
- New appointments during the month
- Employees who left during the month
- Open vacancies
- Absence trends
- Documents requiring renewal

## Tools
- Microsoft Excel
- PivotTables
- Charts and graphs
- Formulas and data validation
- Microsoft PowerPoint for management presentations

## HR Value
HR analytics helps management identify patterns, monitor workforce changes, allocate resources, and make evidence-based decisions.

## Data Privacy
This is a demonstration project. Any sample dataset must use fictional data. Do not publish actual employee names, identity numbers, salaries, medical information, or confidential company records.
