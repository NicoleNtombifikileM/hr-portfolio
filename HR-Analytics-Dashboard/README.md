# HR Analytics Dashboard

## Project Overview
This project demonstrates how Microsoft Excel can be used to organise employee information and present basic HR workforce statistics in a dashboard format.

The dashboard uses fictional employee data to demonstrate practical HR reporting and data presentation skills.

## Project Objectives
- Summarise the total number of active employees.
- Group employees by department.
- Summarise employees by work location.
- Present workforce information in a visual chart.
- Practise preparing clear, professional HR reports.

## Tools Used
- Microsoft Excel
- GitHub

## Dashboard Features
- Total active employee count
- Employee counts by department
- Head Office employee count
- Column chart showing employees by department

## HR Skills Demonstrated
- HR data organisation
- Employee headcount reporting
- Departmental workforce analysis
- Basic dashboard development
- Data visualisation
- HR reporting and documentation

## Business Value
A well-organised HR dashboard can help HR professionals summarise workforce information, identify staffing patterns and communicate employee statistics to management.

## Data Privacy
The employee information used in this project is fictional and intended for demonstration and learning purposes. No confidential employee records are included.

## Future Improvements
- Automate employee counts using Excel formulas.
- Add pivot tables and interactive filters.
- Improve dashboard formatting and visual presentation.
- Expand workforce reporting measures.
